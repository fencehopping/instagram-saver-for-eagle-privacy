Privacy Policy

Instagram Saver for Eagle · Last updated September 21, 2026

Instagram Saver for Eagle has one purpose: to save Instagram media selected by the user to the user's locally running Eagle library.

Data the extension accesses

When the user clicks the Eagle save button on an Instagram post, the extension may access the visible post's media URL, source URL, creator name, caption, and timestamp. It also stores extension settings and a local record used to warn about duplicate saves.

How data is used

The selected post data is sent only to the Eagle application running on the user's own computer through Eagle's local API at localhost or 127.0.0.1.

The extension does not send data to the developer, use analytics, serve advertising, sell data, or share data with third parties.

Data storage

Settings are stored with Chrome extension storage. Duplicate-save records are stored locally in the browser. Users can remove this data by clearing the extension's storage or uninstalling the extension. Media saved to Eagle is controlled by the user inside Eagle.

Permissions

  • Instagram access adds the save control and reads only the post the user chooses to save.
  • Localhost access communicates with the user's locally running Eagle application.
  • Storage access saves settings and duplicate-save records.

Security

The extension does not load or execute remote code. Communication with Eagle remains on the user's local computer.

Contact

For privacy questions or support, use the Support link on the extension's Chrome Web Store listing.

Affiliation

This is an independent, unofficial extension. It is not affiliated with, endorsed by, or sponsored by Instagram, Meta, or Eagle.
